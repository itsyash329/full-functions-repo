## 📋 How It Works

1. Submit a long URL.
2. Generate a unique short code.
3. Share the shortened link.
4. Users are redirected instantly.

### Example

Original URL:

```text
https://example.com/articles/how-to-build-a-link-shortener
```

Shortened URL:

```text
https://heaven-alliance.vercel.app/abc123
```
